# Project Management and Task Tracking Dashboard

## Project Overview
This project presents an interactive Power BI dashboard for monitoring project progress, task status, team workload, and overdue tasks.

## Objectives
- Monitor total, completed, pending, and overdue tasks.
- Analyse task distribution across employees.
- Track completion rates for individual projects.
- Filter results by project and task priority.

## Tools and Technologies
- Microsoft Power BI Desktop
- Power Query for data preparation
- DAX for measures and calculations
- GitHub for project hosting

## Key Features
- Interactive KPI cards
- Task Status Distribution chart
- Team Workload Distribution chart
- Project Completion by Project chart
- Project Name and Priority slicers

## Project File
`Project_Management_Dashboard.pbix`

Download the Power BI file from this repository and open it using Power BI Desktop to explore the report.

## How to Use
1. Download the `.pbix` file.
2. Open it in Power BI Desktop.
3. Use the slicers to filter projects and task priorities.
4. Explore the charts and KPI cards to analyse project performance.
